# Backend Service: Tasteorama API

Це основний бекенд-сервіс для платформи з рецептами, який забезпечує керування користувачами, рецептами, категоріями та інгредієнтами.

📋 Опис проєкту
Система дозволяє користувачам переглядати рецепти, здійснювати пошук за різними критеріями, а також керувати власним контентом та списком обраного.

Основні функціональні можливості:
Автентифікація: Реєстрація, логінізація, вихід із системи (JWT).

Користувачі: Отримання поточної інформації про профілі.

Рецепти: Пошук (за категорією, інгредієнтом, назвою), перегляд деталей, створення власних рецептів, керування списком "улюблених".

Довідники: Отримання списків категорій та інгредієнтів.

🚀 Технологічний стек
Мова: Node.js / TypeScript

Фреймворк: Express.js

База даних: MongoDB

Документація: Swagger

🛠 Налаштування та запуск
Клонування репозиторію:

Bash
git clone [https://github.com/ViktoriiaVeremiichuk/Tasteorama_project-7_backend.git)]
cd [назва-папки]
Встановлення залежностей:

Bash
npm install
Налаштування змінних оточення (.env):
Створіть файл .env на основі .env.template

Запуск серверу:

Bash
npm run dev

📑 Ендпоінти
Auth (/api/auth)
POST /register — Публічний: Реєстрація нового користувача.

POST /login — Публічний: Логінізація.

POST /logout — Приватний: Вихід користувача.


Users (/api/users)
GET /current — Приватний: Дані поточного користувача.


Recipes (/api/recipes)
GET / — Публічний: Пошук за категорією/інгредієнтом/назвою (з пагінацією).

GET /:id — Публічний: Детальна інформація про рецепт.

POST / — Приватний: Створення власного рецепту.

GET /my-recipes — Приватний: Власні рецепти.

DELETE /:id — Приватний: Видалення власного рецепту.

POST /favorite/:id — Приватний: Додати до улюблених.

DELETE /favorite/:id — Приватний: Видалити з улюблених.

GET /favorites — Приватний: Отримання улюблених рецептів.


Довідники
GET /api/categories — Публічний: Список категорій.

GET /api/ingredients — Публічний: Список інгредієнтів.
